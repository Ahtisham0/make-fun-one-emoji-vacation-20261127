One emoji for the dream vacation: 🏝 — a desert island. Turquoise water,
white sand, one palm, nowhere else to be. A postcard at a glance, no words.

`main.ts` writes that single emoji to `/output/entry.txt` (one code point,
4 bytes) and verifies the file round-trips exactly.
